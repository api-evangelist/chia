# Chia Network

> Chia is a decentralized, layer-1 blockchain (native coin XCH) using Nakamoto-consensus Proof of Space and Time as an energy-efficient alternative to Proof of Work. Its reference client is an open-source Python node that runs a full node, farmer, harvester, timelord and wallet, and exposes a local JSON-RPC API (mutual-TLS) plus the `chia` CLI. On-chain smart transactions are written in Chialisp/CLVM, and the network supports CATs (tokens), NFTs, DIDs, offers, DataLayer and DAOs.
